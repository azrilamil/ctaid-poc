# Assets

## Hero illustration

| Field | Value |
| --- | --- |
| File | `app/assets/hero_heart_lungs.svg` |
| Generated by | `app/artwork.py` (`build_svg()`), also runnable as `python -m app.artwork` |
| Author | This project, written by Mohd Azril Amil with AI-assisted development |
| License | MIT, same as the repository (`LICENSE`) |
| Source | Original geometric composition drawn in SVG markup, no third party asset |
| Contains | Stylised lungs, bronchial tree, heart, vessel trace, CT scan rings, data ticks |
| Text in the image | "SYNTHETIC PATTERN FIELD" and "Generated illustration, not a scan of a person" |
| Accessible name | `role="img"` with an `aria-label` and a `<desc>` element |

The previous personal site used two photographic images for its hero band. Those
were not reused: their licenses were not established, and they showed a real
person's imaging. This project draws its own illustration instead, which keeps
the demo free of any third party media.

### Regenerating

```bash
python -m app.artwork
```

The module writes the file if it is missing, and the app calls `ensure_hero()` on
every page load, so a fresh clone renders without a manual step. Deleting the file
and rerunning reproduces it byte for byte.

## Screenshots

`docs/screenshots/` holds placeholder slots for capture of the running app. They
are marked as placeholders in `docs/screenshots/README.md` until real captures are
committed. No screenshot in this repository is a mock up of a different product.

## Fonts

The app asks for `Inter` if the visitor happens to have it, then falls back to
system UI fonts (`Segoe UI`, `Helvetica`, `Arial`). No web font is bundled or
fetched, so there is no font license to track and no third party request at page
load.

## Charts

All figures are drawn at run time by Plotly from the synthetic dataset. There are
no exported chart images in the repository.

## What is not used

- No stock photography, no generated photo realistic images.
- No imaging from the original research project.
- No logos from any institution, hospital or vendor.
- No third party research figures.
