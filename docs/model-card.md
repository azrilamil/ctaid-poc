# Model card: CTAID POC demo classifiers

## What this is

Four classifiers trained by this repository on `data/synthetic_features.csv`, a
fully synthetic table generated by `scripts/generate_synthetic_data.py`. The card
exists so nobody mistakes the demo for a validated model.

**Not a medical device. Not a diagnostic tool. Trained only on fake data.**

## Data

| Item | Value |
| --- | --- |
| Source | `data/synthetic_features.csv`, generated in this repository |
| Rows | 2100 (700 records x 3 vessels) |
| Features used | 65 numeric columns |
| Excluded | `Record ID`, `Vessel`, the target column |
| Target | `Pattern`, 4 classes, labels `Pattern A` to `Pattern D` |
| Column note | The CSV stores the target under the internal column name `Diagnosis`; every screen shows it as `Pattern` through a display alias in `app/schema.py` |
| Class priors | 0.30, 0.26, 0.24, 0.20 |
| Split | 75 / 25 stratified, seed 42 |
| Missing values | none; the pipeline imputes medians as a safety net |

The classes carry a small injected signal (a per class shift on a handful of
features) so that a classifier can learn something. That signal is a property of
the generator, not of any human anatomy.

## Models

| Key | Estimator | Preprocessing | Note |
| --- | --- | --- | --- |
| `logistic_regression` | `LogisticRegression(max_iter=2000, C=1.0)` | median impute, standard scale | fast linear baseline |
| `random_forest` | `RandomForestClassifier(n_estimators=200, min_samples_leaf=2)` | median impute, standard scale | non linear, has importances |
| `svm` | `CalibratedClassifierCV(SVC(rbf, C=2.0), method=sigmoid, cv=3)` | median impute, standard scale | calibrated probabilities |
| `gradient_boosting` | `GradientBoostingClassifier()` | median impute, standard scale | additive trees |

## Measured metrics

`python scripts/train_demo_model.py` on the committed dataset, 2100 rows, 25
percent held out. Macro averages over the four classes.

| Model | Accuracy | Precision | Recall | F1 | ROC AUC |
| --- | --- | --- | --- | --- | --- |
| Logistic Regression | 0.7410 | 0.7384 | 0.7348 | 0.7356 | 0.9163 |
| Random Forest | 0.8419 | 0.8426 | 0.8435 | 0.8395 | 0.9595 |
| Support Vector Machine | 0.7371 | 0.7358 | 0.7305 | 0.7313 | 0.9028 |
| Gradient Boosting | 0.8267 | 0.8250 | 0.8305 | 0.8249 | 0.9593 |

These numbers describe how well a model recovers the generator's own class
signal. They say nothing about atherosclerosis, CT images, or any person. A high
score here is a check that the training path works, not a finding.

## Intended use

- Demonstrating a training and evaluation workflow in a portfolio.
- Showing metric, confusion matrix, ROC and importance rendering.
- Exercising the prediction, upload and logging paths end to end.

## Out of scope use

- Any clinical decision, triage, screening or patient communication.
- Any claim about plaque, stenosis, calcium burden or risk.
- Benchmarking against real cohorts or published model performance.
- Redistribution as a medical model or as a research artifact.

## Limitations

1. The target is invented. There is no ground truth to be right or wrong about.
2. Class effects are linear-ish shifts on a few features, which flatters every
   classifier compared with real imaging texture data.
3. The feature set is a texture and shape description of a segmentation, not an
   image model. No pixel data is ever seen.
4. Random Forest and Gradient Boosting lead on accuracy. That ordering is a
   property of this generator and must not be read as a general result.
5. Held out metrics come from one split at one seed. There is no cross
   validation, no nested tuning and no confidence interval in the UI.
6. Probabilities are plausible, not calibrated on anything real. The SVM path
   uses sigmoid calibration internally to expose probabilities at all.

## Ethical notes

- No real person contributed data to this repository.
- Class labels avoid clinical vocabulary on purpose: `Pattern A` to `Pattern D`.
- Every page repeats "Demo with synthetic data, not a medical tool."
- The project credit names the designer and lead only, with no institution.

## Reproduce

```bash
python scripts/generate_synthetic_data.py
python scripts/train_demo_model.py
pytest -q
```

Artifacts land in `models/` and are git ignored; retraining takes a few seconds.
